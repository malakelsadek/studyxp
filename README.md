# Study XP - A gamified social study space

- A 2D pixel art website where the core feature is a shared timer across multiple people
- You can join rooms either one off rooms or you create your own room where people are invited 
- And there will be some microtransactions for cosmetics and also you can buy them as well with money you get from studying
- There will be chat for room and one on one and also table chats 
- and you can add friends as well, but it will have study features
Study featrues:
-  shared timer, pomodoro or stopwatch
- shared to do list or personal
- tile based system where you can move different features around the screen
- character customization
- login page to save info 
- study stats

Basicall a big 2d room, can have tables and a lounge to  chill as well
